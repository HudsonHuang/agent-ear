# 个人开发者 / AI 工具在中国互联网做宣发：渠道与成本调研

> 调研时间：2026-11-11（Asia/Shanghai）。方法：公开网页检索 + 平台官方页面抓取。
> 数据可信度分三级：**① 官方/平台原文**（最可信）；**② 媒体/服务商公开报价**（可信但有时效性）；**③ 社区经验/个人复盘**（只作量级参考）。
> 凡未查到公开数字的，明确写「未查到」，并给出社区经验区间，不编造精确值。

## 二、B站：报价与真实行情（重点）

### 2.1 商单报价（按粉丝量）

平台官方（花火）没有公开价目表，价格由 UP 主自主报价 + 双方议价，因此只有媒体/服务商统计与个案。

| 粉丝量 | 报价区间 | 来源与时间 |
|---|---|---|
| 1 万粉 | 约 **1000 元/条**（基础报价） | 社区经验总结，2026-10（③） |
| 1-5 万粉 | **800-2500 元/条**（10 分钟内测评类）；知识类 +30% | 新榜素人推，2023 Q2 案例（②） |
| 5-10 万粉 | **未查到**可靠公开区间 | — |
| 10 万粉 | **未查到**可靠公开区间；2025 年多个信源称「价格血崩」 | — |
| 50 万粉 | **未查到**；个案：57 万粉 UP 自述「现在一期商单价格不如去年 5 万粉时的一半」 | B站 UP 主本人回应，2024-10（③） |
| 60 万粉 | 个案爆料 **1000 元/条** | 微博爆料/虎扑转载，2025-01（③，极端个案） |
| 100 万粉 | **未查到** | — |

**结论（重要）**：B 站商单没有稳定的「粉丝数×单价」公式。2024-2025 年市场整体压价，头部/中部价格下跌明显；同粉丝量下，**科技/数码区 > 生活区**，**定制视频 > 植入 > 动态**。动态报价通常是视频的 1/5-1/3（社区经验，未查到公开统计）。

### 2.2 自己做的成本与起量

- **制作时间**：一条 5-10 分钟科技区视频，传统流程约 **27 小时**；用 AI 辅助（脚本、字幕、封面）可压到 **5-8 小时**（③，2026-10 个人开发者复盘）。
- **起量**：新号单条播放 **几百-几千**是常态；知识区是 B 站流量最大的分区之一（该复盘称平台约 40% 流量在知识区，③，未获官方确认）。
- **内容形式**：测评/对比（「X vs Y」）、教程（「3 分钟用 XX 做完 YY」）、整活/挑战、一周 AI 盘点。工具类最适合**教程+对比**，纯功能介绍几乎没量。
- **官方扶持**：B 站有「**新星 UP 扶持计划**」（新人首稿奖金+流量扶持，官方页面 cv17458216）与「星计划任务」（官方 blackboard）。但**创作激励已大幅缩水**：2024 年下半年起「基本取消」（UP 主原文），10 万播放收益 **不到 10 元**，20 万播放约 **4 元**（媒体采访，2025-04）。
- **外链**：B 站视频简介可放文字链接，但站外链接会触发跳转提示、且部分场景被折叠；评论区放链接/二维码容易被吞或限流。**未查到官方明文允许 GitHub 链接的条款**；实操上「简介放 GitHub + 置顶评论说明」是常见做法，但不要放短链/二维码（③）。

### 2.3 坑

1. 硬广/口播广告会被限流，必须走花火报备「商业推广」。
2. 新号前 10 条视频基本没有推荐，播放量几百是正常的。
3. 数码/科技区商单集中在 10-50 万粉，1 万粉以下基本接不到品牌单，只能置换。
4. 充电视频（付费）平台会给推流，是比商单更稳的变现方式（UP 主自述：10 期广告 ≈ 1000 人充电）。

## 三、小红书：报价与流量逻辑（重点）

### 3.1 报价（蒲公英）

| 粉丝量 | 图文报价 | 来源 |
|---|---|---|
| 0-1000 粉 | **约 50 元**或纯置换 | 社区总结，2025（③） |
| 1000-5000 粉 | **50-100 元/篇**（视频略贵） | 同上（③） |
| 5000-1 万粉 | 家居/护肤类可到**粉丝数的 10%**（即 500-1000 元） | 同上（③） |
| 1-5 万粉 | **300-1500 元/篇** | 新榜，2023 Q2（②） |
| 5-10 万粉 | **1000-3000 元/篇** | 新榜，2023 Q2（②） |
| 10 万粉+ | **未查到**可靠公开区间 | — |

> 2023 年数据放到 2026 年建议打 7-8 折参考；实际成交受类目（美妆/3C 高，工具/效率低）、互动率、是否含置换影响。

### 3.2 流量逻辑与内容形态

- 小红书是**搜索+推荐**双引擎，但技术类内容**天然流量差**：平台男性/极客用户占比低，「程序员做小红书」的公开复盘多为「26 天开始怀疑人生」（③）。
- 能起量的形态：**封面大字报 + 清单体**（「5 个免费 AI 工具」「我用它整理了 1 万张照片」）、**前后对比图**、**避坑/省钱**。纯代码、纯 CLI 截图基本没量。
- 照片库存管理这类**可视化强、生活场景强**的工具，比音频 CLI 更适合小红书；音频 CLI 更适合 V2EX/少数派/GitHub。

### 3.3 外链与坑（官方明文）

- **不能放外链**。2025-03-12 起施行的《交易导流违规管理细则》明确：禁止通过**笔记、评论、置顶、用户资料**等引导站外交易，包括「发布其他平台的链接、口令、截图、水印、二维码、小程序」；处罚从警告、限流、限制直播到**永久封号**（①，凤凰网科技报道官方细则）。
- 实操：只能引导「主页看简介」「私信」，且频繁私信会被判导流；专业号可挂载店铺/留资组件，个人开发者一般没有。
- 技术类笔记容易被判「营销号」，新号发 3 条带工具名的笔记就可能限流（③）。

## 四、其余渠道（简版）

### 即刻
- AI/独立开发者氛围最浓的中文社区，有「AI 探索站」「独立开发」等圈子；发「build in public」类动态容易获得同行转发（③）。
- **未查到**公开的曝光/带量统计。社区经验：一条有图的动态几十-几千浏览，带来 **10-100 UV**；被大 V 转发才可能破千。
- 坑：即刻用户「看热闹多、转化少」；直接发广告会被折叠；需要先养号、多互动。

### 知乎
- 自答：选「已有一定热度、但回答质量差」的问题，写长文+图，排名进前 3 后可以吃长尾；技术问题流量远小于「副业/赚钱/软件推荐」类问题。
- **知+**：官方付费推广，按 CPC 计费，需通过代理商开户充值；**公开单价未查到**（代理商页面只写「按点击付费」，无公开刊例）。社区经验 CPC 约 0.5-3 元、起投几千元（③，不可作为报价依据）。
- 坑：回答带链接会被判广告；「好物推荐」需要权限；知乎用户对软文识别能力强。

### V2EX
- 官方数据：**75 万**注册用户，以互联网/游戏/媒体从业者为主（①）。
- 发帖：`分享创造`（/go/create）是作品展示区，`分享发现`（/go/share）适合发工具；**没有专门的「广告」节点**，纯广告会被降权/删帖/封号。
- 官方规则明确：**「请不要把 AI 生成的内容发送到这里」**（2025-07 修订，①）——用 AI 写推广文案直接发，风险很高。
- 付费推广（官方）：PRO 充值 **满 20 美元**起，按充值金额分配首页/内容页右侧展示权重（①）；全站 A1 广告 **40000 元/月**（①）。
- 效果：首页热门帖几百-几千 UV；普通帖几十-几百（③）。坑：新号发链接容易被判广告；「自荐」要写清楚，别装用户。

### 少数派
- 投稿机制：可直接发布为「社区作品」（不要求首发），或「投稿编辑部」（要求首发，3 个工作日内通知，①）。
- 稿酬（官方，2026-10 更新）：首页文章 **110 元/千字**（例外首页 60 元/千字，上限 360 元）；互动加成上限 200 元；会员内容 140 元/千字；付费栏目作者 80% 分成，定价 29/69/129 元（①）。
- 时间：3000 字+截图，约 **8-20 小时**；首页文章阅读几千-几万，导流 UV 几百-几千（③）。
- 坑：偏「生活方式/效率/软件体验」，纯 CLI 工具需要包装成「工作流」；审稿偏好首发；被拒不会详细反馈。

### 微信公众号
- 自建号：无推荐流量，冷启动阅读 **0-几十**，需要从其他平台导流；打开率行业均值约 1-5%（③）。
- KOL 报价（2025-10）：尾部几百-3000 元/条；腰部 **5000-3 万**；头部 **5 万+**；按阅读量计费约 0.3-1.5 元/阅读（②）。
- 坑：技术类公众号报价低、转化好，但粉丝量普遍小；投放要走「互选平台」或签合同，私下交易容易被刷量。

### 掘金 / CSDN / InfoQ / 机器之心 / 量子位
- **掘金**：免费发布；官方「金石计划」面向 Lv4-Lv8 创作者，按「被官方推荐」的文章瓜分奖池（8000/12000/10000 元），示例单篇约 **12-20 元**；优秀作者额外 200 元（①）。适合拿曝光，不适合赚钱。
- **CSDN**：免费，SEO 长尾强，但广告多、读者偏初级；适合铺搜索关键词（③）。
- **InfoQ 中国**：接受投稿，要求 3000-4000 字深度稿，**明确拒绝软文/公司宣传/入门教程**；版权三选一（归 InfoQ / 保留 / CC）（①，官方投稿指南）。审稿周期未查到。
- **机器之心 / 量子位**：以编辑约稿、转载、选题策划为主；**未查到公开投稿邮箱/稿费/收费报价**。冷启动项目基本排不上，除非有论文/大厂背景或爆款数据。

### Product Hunt / Hacker News / Reddit
- 可行性：三者在中国大陆**直连均不可用**（本次实测 github.com、news.ycombinator.com 直连失败，走代理 200）；需要稳定的海外网络、海外手机号/邮箱、英文文案，且要按美国时区发布（PH 太平洋时间 00:01）。
- 带量：PH 首日几百-几千 UV；HN 首页 1-5 万 UV；Reddit 单帖几百-几万（均为社区经验，③，未查到官方统计）。
- 坑：HN 新账号发 Show HN 容易被 flag；Reddit 多数 sub 有 karma/年龄门槛，直接发链接会被删；PH 需要 hunter/预热，冷启动很难进前 10。

### GitHub Trending
- 官方没有公开算法；社区经验：**24 小时内 100-300 star 的增速**才可能进 Trending，且需要持续 2-3 天（③，未查到官方阈值）。
- 中文 Trending 是独立榜单（`github.com/trending?spoken_language_code=zh`），竞争小于全球榜。
- 可操作手段：发 HN/Reddit/V2EX/即刻导流；找 awesome-list 收录；请朋友 star 时**不要同一时间批量**（会被判刷）；README 要有 GIF/一句话价值主张。
- 坑：star 暴涨但无真实用户，会掉榜且被社区标记；中文项目进全球榜难度极高。

## 五、给这两个项目的建议

**音频理解 CLI 工具**
1. 主战场：**V2EX 分享创造 + GitHub + HN（英文）+ 少数派**。CLI 用户在这些地方。
2. B 站做一条「5 分钟把播客/会议录音变成结构化笔记」的教程视频，成本 5-8 h，作为长期落地页。
3. 小红书/公众号不建议作为主力（人群不匹配）。

**照片库存管理网页工具**
1. 主战场：**小红书（前后对比图+清单体）+ 即刻 + B 站（一周盘点/教程）**。
2. 小红书先发 5-10 条「照片管理避坑」干货养号，再软植入；不要放链接，引导主页。
3. 可投 1-2 个千粉/万粉家居/效率类博主（500-1500 元/篇），比投技术号划算。

**总预算建议（3 个月）**：0 元自然流量为主；预留 **2000-5000 元**试投小红书/公众号尾部 KOL；V2EX PRO 充 $20-50 试水；不建议早期买 B 站商单（1 万粉以下没效果）。
